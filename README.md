# US Crime Data Analysis

## Project Overview
This project explores US crime data to identify crime patterns, trends, and geographic hotspots using data analysis and visualization techniques.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Power BI
- Folium

## Key Activities
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Crime trend and pattern analysis
- Geographic crime visualization
- Interactive dashboard creation using Power BI

## Files
- `US_Crime_analysis.ipynb` — Python analysis and visualizations
- `crime_dashboard.pbix` — Power BI dashboard

## Objective
To explore crime data, discover meaningful patterns, and present insights through visualizations and dashboards.

## Known Issue
The interactive crime heatmap may not display its background map tiles because of tile-server access or URL errors. The heatmap requires a working tile provider and an internet connection.
